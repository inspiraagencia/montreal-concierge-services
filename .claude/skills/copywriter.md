# Skill: Copywriter & Content Writer

## Descripción
Skill especializado en redacción de contenidos SEO-optimizados, copywriting persuasivo y creación de textos para páginas web, blogs, emails y materiales de marketing.

## Capacidades

### 1. Copywriting SEO
- Redacción con **palabras clave** integradas naturalmente
- Meta descriptions optimizadas (150-160 caracteres)
- H1/H2/H3 jerarquía correcta
- URL slugs descriptivos
- Estructura de contenido para buscadores

### 2. Textos Persuasivos
- Headlines impactantes
- CTAs (Call-to-Action) efectivos
- Propuestas de valor claras
- Argumentos de venta convincentes
- Diferenciación competitiva

### 3. Contenido Multiidioma
- Redacción en Francés e Inglés
- Adaptación cultural y local
- Tonalidad apropiada por idioma
- Consistencia de marca EN/FR

### 4. Tipos de Contenido
- **Páginas Web:** Home, servicios, about, contact
- **Blog Posts:** Articles SEO long-tail
- **Email Marketing:** Campañas y newsletters
- **Product Descriptions:** Fichas técnicas
- **Landing Pages:** Optimizadas para conversión
- **Testimonios:** Guiones y rewrite

### 5. Optimización Técnica
- Keyword density (1-2%)
- Longitud de contenido óptima
- Estructura de párrafos (2-3 líneas)
- Legibilidad (Flesch-Kincaid)
- Internal linking suggestions

## Parámetros Típicos

### Tone of Voice
- Profesional pero accesible
- Confianza y autoridad
- Beneficio-centrado (no feature-centrado)
- Local (Montreal, Rive-Sud)

### Keywords Objetivo
```json
{
  "primary": ["concierge services", "nettoyage commercial", "gestion Airbnb"],
  "secondary": ["Montreal", "Riviera Sud", "professional cleaning"],
  "long-tail": ["commercial cleaning services Montreal", "affordable property management"]
}
```

### Estructura SEO
```
H1: Keyword principal + valor (1 por página)
H2: Keyword secundarias (2-4)
H3: Subtópicos (bajo H2)
Meta: 150-160 chars con keyword
Alt text: Imagen + contexto + keyword
```

## Flujo de Trabajo

### 1. Análisis
- [ ] Identificar keywords target
- [ ] Analizar competencia
- [ ] Definir audience
- [ ] Establecer goal (conversión, educación, info)

### 2. Estructura
- [ ] Crear outline con H1-H3
- [ ] Identificar secciones principales
- [ ] Planificar CTA placement
- [ ] Definir extensión (300-2000 words)

### 3. Redacción
- [ ] Escribir con keywords naturales
- [ ] Mantener tono consistente
- [ ] Usar listas y bullets para legibilidad
- [ ] Agregar ejemplos/números

### 4. Optimización
- [ ] Verificar keyword density
- [ ] Optimizar meta description
- [ ] Revisar H1-H3 hierarchy
- [ ] Crear URL slug
- [ ] Sugerir internal links

### 5. Traducción (EN/FR)
- [ ] Adaptar no solo traducir
- [ ] Mantener keywords localizadas
- [ ] Preservar tono en ambos idiomas
- [ ] Verificar URLs/slugs EN y FR

### Email Copywriting
```
Subject Line: Urgent + Value + Specificity
Preview Text: 2-3 palabras clave
Body: Beneficio → Social Proof → CTA
Signature: Nombre + Título + Contact
```

- Content depth (comprehensive > thin)
- User intent alignment
