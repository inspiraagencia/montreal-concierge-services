## 🚀 Cómo Usar los Skills en el Dashboard

### Escenario 1: Crear Nueva Página del Dashboard
```
1. Usa /frontend-design (referencia: interface-design-pro)
2. Especifica: "Crear página dashboard con cards profesionales"
3. Usa react-best-practices para optimización
4. Usa theme-factory para aplicar colores corporativos
```

### Escenario 2: Mejorar Tabla de Solicitudes
```
1. Usa /frontend-design (referencia: frontend-design-pro)
2. Especifica: "Tabla sorteable, filtrable con búsqueda"
3. Usa senior-frontend para optimización de lista grande
4. Usa react-view-transitions para animaciones
```

### Escenario 3: Crear Sistema de Gráficos
```
1. Usa /frontend-design con canvas-design
2. Integra Recharts
3. Usa senior-frontend para data loading
4. Aplica tema con theme-factory
```

### Escenario 4: Optimizar Performance
```
1. Usa /senior-frontend
2. Usa react-best-practices
3. Analiza con senior-backend
4. Usa skill-creator para evaluar mejoras
```
